Mit GitHub verbinden

So bekommst du den Zugangsschlüssel
  1. Öffne auf GitHub: Profilbild → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Klick „Generate new token“, Name z. B. „Kiezkinder“, Ablauf 1 Jahr.
  3. Bei „Repository access“: „Only select repositories“ und dein Kiezkinder-Repo wählen.
  4. Bei „Permissions“: „Contents“ auf „Read and write“, „Actions“ auf „Read and write“.
  5. „Generate token“ klicken und den Schlüssel hier einfügen.
Ein Wochenplan-Eintrag wiederholt sich jede Woche am gleichen Tag, solange er gültig ist. Kommt ein neues Monatsprogramm, beende die alten Einträge mit „Alle beenden am …“ und trag die neuen ein.
